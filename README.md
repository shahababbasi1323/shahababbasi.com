# shahababbasi.com

Static HTML site for [shahababbasi.com](https://shahababbasi.com) — SEO Expert & Digital Marketing Strategist.

## Build

```bash
node build/build.js
```

Output goes to `dist/`. Deploy on Cloudflare Pages with:
- **Build command**: `node build/build.js`  
- **Output directory**: `dist`

## Structure

- `build/build.js` — Static site generator (zero dependencies)
- `src-static/data/` — JSON data for all pages
- `src-static/templates/` — HTML templates
- `src-static/assets/` — CSS, JS, images
